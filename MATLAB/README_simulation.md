# 誘導モータ（IM）ベクトル制御 MATLAB シミュレーション

## 概要

本フォルダには、誘導モータ（Induction Motor: IM）のベクトル制御アルゴリズムを
MATLAB スクリプトとして再現したシミュレーションが含まれる。

シミュレーションの目的は次のとおりである。

- 組み込みソフトウェア（RH850/C1M 用 PE1 実装）の制御ロジックを MATLAB 上で再現し、
  制御応答を視覚的に確認する
- モータパラメータや PI ゲインの影響をシミュレーション上で調整する
- 仕様書の制御ブロック図との対応を確認する

## 制御構造（デュアルレート）

本シミュレーションは組み込みソフトと同様の「2 種類の演算周期」を模倣している。

### 低速タスク（1 ms 周期）
`fi_1ms_inv0_idqcom.c` に対応する処理

- トルク指令値（`f4_tq_inv0_ref`）のレートリミット処理
  - 急激なトルク変化を防ぐため、1ms あたりの変化量を `dTe_max` に制限する
- トルクマップ補間による d-q 軸電流指令値（`f4_id_inv0_ctrl`, `f4_iq_inv0_ctrl`）の演算

### 高速タスク（100 µs 周期 / PWM 割り込み相当）
`fi_pwm_inv0_idqctrl.c`, `fi_pwm_inv0_syncctrl.c`, `fi_pwm_inv0_svctrl.c` に対応

- 励磁インダクタンス Lm のマップ更新（`mapdata_lm_inv0_1d_map.c`）
- すべり角速度の演算（`fi_pwm_inv0_syncctrl.c`）
- 同期角（磁束位相角）の積分更新（`fi_pwm_inv0_syncctrl.c`）
- d-q 軸電流 PI 制御・電圧指令値演算（`fi_pwm_inv0_idqctrl.c`）
- 電圧指令値の飽和クランプ
- プラントモデル（電圧→電流）の更新 ← **MATLAB シミュレーション専用**
- 発生トルク推定（`f4_tq_inv0_est`）
- 機械系（回転子速度）の更新 ← **MATLAB シミュレーション専用**

## プラントモデルについて

組み込みソフト側は実機を制御するためプラントモデルを持たない。  
本 MATLAB シミュレーションでは、以下の簡易プラントモデルを実装している。

### 電気系（d-q 軸等価回路）

```
d(id)/dt = ( Vd - Rs×id + ωs×Ls×iq ) / Ls
d(iq)/dt = ( Vq - Rs×iq - ωs×Ls×id ) / Ls
```

- `ωs`: 同期角速度 [rad/s]
- `Rs`: 補正後一次抵抗 [Ω]
- `Ls`: 固定子インダクタンス [H]

この式は、定常磁束仮定下での d-q 軸電圧方程式を離散化したものである。  
厳密な誘導モータモデルは 4 次状態方程式だが、制御帯域内の応答確認目的として 2 次に簡略化している。

### 機械系（運動方程式）

```
J × d(ωr)/dt = Te - B×ωr - TL
```

- `J`: ロータ慣性モーメント [kg·m²]
- `B`: 粘性摩擦係数 [N·m·s/rad]
- `TL`: 負荷トルク（現モデルでは 0 を仮定）

## 温度補正・抵抗補償について

組み込みソフトでは、`u1_flag_enable_inv0_r1_cmp`（一次抵抗補正フラグ）および
`u1_flag_enable_inv0_r2_cmp`（二次抵抗補正フラグ）が有効の場合、
推定温度に基づいて一次・二次抵抗を補正する。

本 MATLAB 版では、温度補正を以下のように簡略化している。

```matlab
Rs_cmp = Rs × k_r1_cmp   % k_r1_cmp = 1.0 で補正なし
Rr_cmp = Rr × k_r2_cmp   % k_r2_cmp = 1.0 で補正なし
```

温度依存性を評価する場合は、`k_r1_cmp` / `k_r2_cmp` の値を変更することで
抵抗値の変化を模擬できる。

## トルクマップの簡略化について

組み込みソフト（`mapdata_trq_inv0_map.c`）では、以下の 3 次元マップを使用している。

- 入力軸 1: トルク指令 [N·m]
- 入力軸 2: 回転数 [rpm]
- 入力軸 3: DCリンク電圧 [V]
- 出力: id_ref [A] および iq_ref [A]

本 MATLAB 版では、回転数・電圧依存を無視した **1 次元近似マップ** を使用している。  
これは「低速・定格電圧（48V）」付近での動作を近似したものであり、  
高速域・弱め磁束制御・電圧変動には対応していない点に注意すること。

実機との対応度向上には、以下の対応が必要である。

1. `mapdata_trq_inv0_map.c` の実マップデータ（整数配列）を MATLAB に移植する
2. 回転数・DCリンク電圧を引数とした `interp3` による 3 次元補間を実装する

---

## Lm マップについて

励磁インダクタンス Lm は磁気飽和の影響により d 軸電流（id）に依存して変化する。  
本シミュレーションでは `mapdata_lm_inv0_1d_map.c` の実マップデータを参考にした  
近似テーブルを使用し、`interp1` で線形補間している。

```matlab
Lm = interp1(lm_map_id, lm_map_lm, abs(id_meas), 'linear', 'extrap');
```

id が大きくなると Lm が低下する（磁気飽和）特性を模擬している。

## 使い方

1. MATLAB を起動する
2. カレントディレクトリを本フォルダ（`MATLAB/`）に設定する
3. コマンドウィンドウで以下を実行する:

```matlab
>> im_vector_control_sim
```

4. シミュレーション完了後、以下が自動表示される:
   - グラフウィンドウ（6 つのサブプロット）
   - コマンドウィンドウへの数値サマリ出力

## 既知の制限と改善点

| 項目 | 現状 | 改善方針 |
|------|------|----------|
| トルクマップ | 1次元近似（低速・定格電圧のみ） | 実機 3 次元マップデータを移植し `interp3` 補間に変更 |
| 温度補正 | 固定係数（k_r1_cmp = 1.0） | 温度推定モデルと連動させた動的補正に変更 |
| 電気系プラント | 2 次近似（漏れ磁束無視） | 誘導モータ完全 4 次モデルへ拡張 |
| 負荷モデル | 無負荷（TL = 0） | 粘性・クーロン摩擦・外乱負荷を追加 |
| 弱め磁束制御 | 未実装 | 高速域での id_ref 低減処理を追加 |
| SVPWM デューティ | 未実装（電圧指令のみ） | UVW 相電圧・Duty 比の演算を追加 |
